## How to Host on GitHub Pages
1. इस कोड को अपने GitHub Repository में पुश करें।
2. Repository के **Settings** में जाएँ।
3. **Pages** टैब पर क्लिक करें।
4. **Build and deployment** के अंदर 'Source' को "GitHub Actions" पर सेट करें।
5. प्रोजेक्ट में दी गई `.github/workflows/deploy.yml` फ़ाइल ऑटोमैटिकली आपकी साइट को `https://your-username.github.io/ggtv-news/` पर लाइव कर देगी।

## Gemini API Key Security
अगर आप AI Summary फीचर का इस्तेमाल करना चाहते हैं, तो GitHub के **Settings > Secrets and variables > Actions** में जाकर अपना `API_KEY` स्टोर करें।
